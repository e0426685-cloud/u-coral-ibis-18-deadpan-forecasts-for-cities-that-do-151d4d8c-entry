"Deadpan Forecasts for Cities That Do Not Exist": one absurd but believable
weather line for an invented city, judged by a dry TV meteorologist.

`main.py` (Python standard library only) writes a single deadpan forecast
of at most 160 characters to `/output/entry.txt`:

> In Quibbleford, a high of 41 degrees and light drizzle of warm custard;
> umbrellas advised, as the custard is both local and legally binding.

Run it with:

```sh
python3 main.py
```
